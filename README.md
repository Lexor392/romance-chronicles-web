# Lumen — истории на выбор

Оригинальная веб-игра в жанре интерактивных романтических историй. Проект создан с нуля и не содержит текстов, персонажей, музыки или графики из сторонних коммерческих игр.

## В проекте

- 3 истории по 6 глав;
- выборы, параметры отношений и 3 концовки на историю;
- оригинальные SVG-иллюстрации персонажей и сцен;
- процедурная атмосферная музыка через Web Audio API;
- автоматическое сохранение прогресса в `localStorage`;
- адаптивный интерфейс для компьютеров и мобильных экранов.

## Локальный запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
npm run preview
```

Тесты игрового движка:

```bash
npm test
```

## GitHub Pages

Workflow `.github/workflows/deploy.yml` собирает приложение и публикует папку `dist` через GitHub Pages после push в `main`.

Для проекта используется относительный Vite base path (`./`), поэтому он корректно работает в репозитории `romance-chronicles-web`.

## Лицензия ассетов

SVG-иллюстрации и исходный код проекта — оригинальные материалы этого репозитория. Аудио не хранится отдельными файлами: звуковой фон синтезируется локально в браузере и не использует сторонние записи.
