# После последнего звонка

Оригинальная русскоязычная визуальная новелла о возвращении Иры в Академию Вершины. Это самостоятельная история с ветвящимися выборами, отношениями, тайной школьного фонда и четырьмя финалами.

## Что внутри

- одна полноценная история на 11 глав;
- четыре сюжетных маршрута: Артем, Никита, Илья и путь Иры к себе;
- диалоги по одной реплике, сцены с фонами и портретами персонажей;
- две локальные музыкальные композиции в формате WAV и переключатели музыки/звуков;
- сохранение главы, выборов, маршрута и открытого финала в `localStorage`;
- простой интерфейс для новичков и адаптивная верстка для мобильного Safari;
- оригинальные SVG-фоны и локальные портретные ассеты, собранные по предоставленному референсу персонажей.

## Локальный запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
npm run preview
```

Тесты игровой логики:

```bash
npm test
```

## GitHub Pages

Workflow `.github/workflows/deploy.yml` собирает приложение и публикует папку `dist` через GitHub Pages после push в `main`.

Для проекта используется относительный Vite base path (`./`), поэтому приложение работает в репозитории `romance-chronicles-web` и при прямом открытии страницы GitHub Pages.

## Лицензия ассетов

Исходный код, SVG-фоны и WAV-музыка созданы специально для этого проекта. Портреты персонажей подготовлены из предоставленного пользователем референса с персонажами истории. Материалы коммерческой игры «Клуб романтики» не используются.
